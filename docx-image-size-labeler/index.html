DOCX Image Size Labeler

Upload a DOCX file to add an image size label immediately above every embedded image, then download the updated DOCX.

The file is processed locally in this browser. PNG, JPEG, GIF, BMP, and WebP images can report original pixel dimensions; other formats still get the DOCX displayed size when Word stores it.
